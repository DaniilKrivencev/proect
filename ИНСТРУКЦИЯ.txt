СЕЙЧАС НА СЕРВЕРЕ
  • Сервис запущен как служба lunka: systemctl status / restart / stop lunka.
  • Обновить код: cd /opt/lunka && .venv/bin/python manager.py backup
    && git pull && .venv/bin/pip install -r requirements.txt && systemctl restart lunka
  • Бот техподдержки (ADMIN_BOT_TOKEN в .env): список всех салонов, вход в любой
    как клиент / хозяин / мастер, телефоны клиентов скрыты. /stop — выйти из режима.
  • Заполнить салон прайсом и мастерами из файла:
    .venv/bin/python manager.py import <папка> salons/<папка>.json

ЧТО УМЕЕТ
  Клиенты:
  • Открывают бота → выбирают услугу → мастера (или «любой свободный»)
    → день → время. Без звонков и переписки.
  • Получают напоминания за сутки и за 2 часа, могут отменить запись.
  • Могут прислать фото желаемого дизайна — оно придёт мастеру.

  Владелец салона (кабинет в Telegram, кнопка «Кабинет»):
  • Записи всего салона или каждого мастера по дням, ручная запись.
  • Мастера: добавить / удалить, какие услуги делает, график, выходные,
    ссылка-приглашение для подключения мастера к боту.
  • Услуги и цены (в т.ч. «от»), база клиентов с заметками,
    «давно не были» + приглашение вернуться, выручка за месяц.
  • Уведомления о каждой записи/отмене и вечерний план салона на завтра.
  • Переписка с клиентками: их вопросы и фото приходят в Telegram с кнопкой
    «💬 Ответить» — она включает режим ответа (всё, что вы пишете, получает
    клиентка). Можно и просто ответить на сообщение свайпом. Все чаты —
    в кабинете → «Чаты».
  • Директор/администратор: кабинет → «Салон» → «Пригласить администратора».

  Мастер (после ссылки-приглашения):
  • Получает только свои записи, отмены и свой план на завтра.
  • В кабинете видит своё расписание, клиентов и меняет свой график.


НЕСКОЛЬКО САЛОНОВ НА ОДНОМ КОМПЬЮТЕРЕ / СЕРВЕРЕ
  Каждый салон живёт в своей папке и ничего не знает о других:
    tenants\zarina\   — салон Зарины: tenant.env (её бот и тип салона) + lunka.db (её база)
    tenants\masha\    — салон Маши:   tenant.env + lunka.db
  • У каждого салона СВОЙ бот в Telegram (создайте в @BotFather командой /newbot).
  • Каждый салон работает отдельным процессом. Если один упадёт — остальные
    продолжат работать, а упавший перезапустится сам (через 5–60 секунд).
  • Тип салона (NICHE в tenant.env): nails — маникюр, hair — парикмахерская.
    От него зависят стартовый прайс и тексты бота.

  Добавить салон:
    1. Создайте новый бот в @BotFather, скопируйте токен.
    2. Дважды щёлкните  добавить_салон.bat  — ответьте на 4 вопроса.
    3. Перезапустите run.bat. Владелец салона открывает своего бота
       и нажимает «Подключить салон».

  Салон из прошлой версии при первом запуске сам переедет в tenants\salon1\
  со всеми записями и клиентами.

  Бот логов один на все салоны — в сообщениях пометка [имя папки салона].
  Команда /status показывает состояние каждого салона.


БОТ В MAX (тот же самый бот, что в Telegram)
  • Клиентки могут записываться и через Telegram, и через MAX — сценарий одинаковый,
    база общая: салон видит всех клиенток в одном списке, мастерам записи приходят
    в тот мессенджер, которым пользуется сам мастер.
  • Как подключить:
    1. Зарегистрируйтесь на business.max.ru как организация, ИП или самозанятый
       и дождитесь проверки профиля.
    2. Создайте там чат-бота и дождитесь модерации.
    3. Возьмите токен: Чат-боты → ваш бот → Расширенные настройки → Настроить.
    4. Дважды щёлкните  подключить_MAX.bat , выберите салон, вставьте токен.
    5. Перезапустите run.bat. Ссылка на бота: https://max.ru/<имя бота>
  • Отличия MAX, о которых стоит знать:
    – в MAX нет постоянного меню внизу экрана — кнопки меню бот показывает
      под своими сообщениями;
    – кабинет в MAX открывается кнопкой «Открыть кабинет» в обычном браузере
      по личной ссылке входа (она действует 30 дней, новую даёт /start).


ЗАПУСК
  1. Дважды щёлкните  run.bat. Первый раз установится всё нужное (3–5 мин),
     окно попросит токен бота — вставьте (правая кнопка мыши) и Enter.
  2. Появится «✅ Бот запущен». НЕ закрывайте окно — пока оно открыто,
     бот работает.


ПЕРВАЯ НАСТРОЙКА САЛОНА
  1. Владелец открывает бота → «Подключить салон». Кто нажал первым —
     тот и владелец.
  2. Если владелец тоже делает маникюр — кнопка «Я тоже мастер».
  3. Кабинет → «Салон»: название, адрес, пара слов для клиентов.
  4. Кабинет → «Мастера» → «Добавить мастера». В карточке мастера
     отметьте его услуги и график, нажмите «Отправить приглашение» —
     мастер откроет ссылку и будет получать свои записи.
  5. Кабинет → «Услуги»: поправьте стартовый прайс под салон.
  6. Ссылку на бота (вкладка «Салон») — в профиль салона, VK,
     Яндекс Карты, 2ГИС.


ЛОГИ ДЛЯ РАЗРАБОТЧИКА (необязательно)
  • При запуске окно один раз спросит «Токен бота логов» — вставьте токен
    служебного бота (или нажмите Enter, чтобы пропустить).
  • Откройте этого бота в Telegram и нажмите «Запустить» — он сразу пришлёт
    «Логи подключены». Подключиться может только аккаунт из LOG_OWNER в .env.
  • Приходят: запуск/падение, ошибки, предупреждения, записи и отмены
    (без имён и телефонов клиенток). Команды: /status, /stop.
  • Если окно закрыть крестиком, Windows завершает программу мгновенно —
    сообщение об остановке может не прийти.

ТЕМА КАБИНЕТА
  • Кнопка с луной/солнцем вверху кабинета или «Салон» → «Оформление»:
    Авто / Светлая / Тёмная.


ВАЖНО ЗНАТЬ
  • Бот работает, пока компьютер включён и окно run.bat открыто.
    Для работы 24/7 нужен сервер (~300–500 ₽/мес) — следующий шаг.
  • Адрес кабинета меняется при каждом запуске. Если кабинет показывает
    ошибку Cloudflare — закройте его и откройте заново из чата с ботом.
  • Данные каждого салона — в tenants\<салон>\lunka.db. Делайте копию папки tenants.
    (Старый файл okoshko.db от самой первой версии больше не используется.)
  • Файл .env содержит токен бота — никому не отправляйте.
  • Удалить мастера можно, только когда у него нет будущих записей:
    сначала отмените или перенесите их.


ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
  «Не получилось установить Python автоматически»
      → скачайте с python.org, при установке галочка «Add python.exe to PATH».
  «Telegram не принял токен»
      → откройте .env Блокнотом и проверьте токен.
  «Кабинет недоступен (нет туннеля)»
      → запись клиентов работает; перезапустите run.bat.
  Кабинет пишет «Кабинет доступен только сотрудникам салона»
      → вы не владелец и не подключённый мастер. Мастеру нужна его ссылка.

Проверка кода:  .venv\Scripts\python -m tests.test_flow
