      maria/       ← «Стрижка у Марии» (парикмахерская)
    salons/        ← файлы прайса для быстрого заполнения (zarina.json…)
  • Код общий — обновили код (git pull), обновились все салоны.
  • Данные у каждого свои — салоны друг друга не видят.
  • Упал один салон — остальные работают, менеджер его перезапустит.
  • Кабинет каждого салона: https://<папка>.<DOMAIN из .env>
    (например https://maria.194-226-99-90.sslip.io) — Caddy настраивается сам.


САМЫЙ ПРОСТОЙ СПОСОБ — ИЗ БОТА ТЕХПОДДЕРЖКИ (без сервера и консоли)
  1. @BotFather → /newbot → скопируйте токен нового бота.
  2. Бот техподдержки → /start → «➕ Добавить салон» (или команда /add).
  3. Название → тип (маникюр / парикмахерская / «✍️ Свой вариант») → токен →
     MAX (можно пропустить). Салон запускается сразу, остальные не перезапускаются.
  4. Владелец: выберите формат заказчика — «💅 Частный мастер» или
     «🏠 Салон с мастерами» — и пришлите его @username в Telegram.
     Бот выдаст ещё и личную ссылку владельца (на случай, если username нет —
     кнопка «🔗 Только ссылка»).
  5. Отправьте заказчику ссылку на бота (или личную ссылку) и инструкцию.
     Он нажимает «Запустить» — и сразу владелец в нужном формате, без выбора.
     Посторонним кнопка «Подключить салон» не показывается.
  Поменять/назначить владельца позже: салон → «👑 Владелец салона».
  Там же видно, кто владелец сейчас, и можно «✖️ Отменить ожидание».


ВРУЧНУЮ НА СЕРВЕРЕ (если бот техподдержки недоступен)
ДОБАВИТЬ ЗАКАЗЧИКА (пример: Мария, парикмахерская)

  1. Новый бот в Telegram — у каждого салона свой:
     @BotFather → /newbot → имя «Стрижка у Марии» → адрес, например
     strizhka_u_marii_bot → скопируйте токен.
     Сразу: /setdescription (описание до 512 знаков), /setabouttext (до 120),
     /setuserpic (аватарка — логотип или фото салона).

  2. (Необязательно) Бот в MAX — на business.max.ru (нужен проверенный
     профиль организации/ИП/самозанятого). Можно позже:
     .venv/bin/python manager.py max

  3. На сервере:
       cd /opt/lunka
       systemctl stop lunka
       .venv/bin/python manager.py add
     Ответы:
       • название — «Стрижка у Марии» (его видят клиенты)
       • имя папки латиницей — maria
       • тип — 1 маникюр / 2 парикмахерская → 2
       • токен Telegram-бота (вставить правым щелчком)
       • токен MAX — Enter, чтобы пропустить
       systemctl start lunka

  4. Проверка: .venv/bin/python manager.py list — салон в списке;
     в боте техподдержки или логов /status — у салона 🟢.

  5. (Если есть прайс заказчика) сделайте файл salons/maria.json по образцу
     salons/zarina.json, загрузите в GitHub и на сервере:
       git pull && .venv/bin/python manager.py import maria salons/maria.json
     Без файла — стартовый прайс парикмахерской, заказчик правит его в кабинете.

  6. Передайте заказчику ссылку на бота: он ПЕРВЫМ нажимает
     «🌸 Подключить салон» и становится владельцем. Сами НЕ нажимайте —
     вы входите в салоны через бота техподдержки.
     Нажали случайно — кабинет → «Салон» → «Пригласить администратора»
     и отправьте ссылку заказчику.

  7. Отправьте заказчику инструкцию для владельца, а его мастерам —
     инструкцию для мастера (docs/ в репозитории или ссылки на документы).

  8. Копия: .venv/bin/python manager.py backup


ЧЕК-ЛИСТ ПЕРЕД ВЫДАЧЕЙ
  [ ] свой бот (Telegram, при желании MAX), описание и аватарка
  [ ] правильный тип салона (маникюр / парикмахерская)
  [ ] владелец — заказчик, а не вы
  [ ] мастера добавлены, графики верные, приглашения отправлены
  [ ] прайс, адрес, телефон заполнены
  [ ] тестовая запись прошла, уведомления пришли
  [ ] свежая копия


ПЕРЕДАТЬ УЖЕ НАСТРОЕННЫЙ САЛОН «С НУЛЯ» (стереть тестовые записи)
  ПРОЩЕ ВСЕГО — в боте техподдержки: салон → «🧹 Подготовить к выдаче заказчику»
  → PIN → «мастеров отвязать» (если в мастерах были вы/тестовые аккаунты) или
  «подключения мастеров оставить». Перед очисткой делается полная копия.
  Удаляются: записи, клиенты, чаты, отзывы с фото, владельцы, режим техподдержки.
  Остаются: мастера, услуги и цены, графики, выходные, название, адрес, телефон.
  Сразу после — назначение владельца (формат + @username). Сервер не трогаем.

  Вручную на сервере (стирает И мастеров, потом их возвращает import):
  systemctl stop lunka
  .venv/bin/python manager.py reset      → 1 → имя папки → ОЧИСТИТЬ
  systemctl start lunka
  (через 10 секунд) .venv/bin/python manager.py import <папка> salons/<папка>.json
  Мастера и прайс вернутся, но ссылки-приглашения мастеров будут НОВЫЕ.


ОТКЛЮЧИТЬ ЗАКАЗЧИКА
  1. .venv/bin/python manager.py backup
  2. systemctl stop lunka
  3. mv tenants/<папка> /opt/архив_<папка>
  4. systemctl start lunka — остальные салоны работают как раньше.
  Вернуть — положить папку обратно в tenants и перезапустить.


ВАЖНО
  • Один бот = один салон. Менеджер не запустится, если у двух салонов один
    бот, и подскажет, где ошибка.
  • tenant.env и .env содержат токены — никому не пересылайте.
  • Тип салона меняется в tenant.env (NICHE=nails / NICHE=hair), но стартовый
    прайс создаётся только при самом первом запуске салона.
