=====================================================================
  КАБИНЕТ ПО ПРЯМОМУ АДРЕСУ (вместо временного туннеля trycloudflare)
=====================================================================

ЗАЧЕМ
  Временный туннель trycloudflare в России работает плохо: кабинет выдаёт
  ошибки 520 / 530, адрес меняется при каждом запуске. На сервере с
  постоянным IP туннель не нужен — кабинет открывается напрямую:
      https://zarina.194-226-99-90.sslip.io
  Сертификат https получает и продлевает программа Caddy — сама, бесплатно.
  sslip.io — бесплатный адрес, который просто указывает на IP сервера.
  Позже можно купить свой домен (см. внизу) — меняется одна строка.


1. УСТАНОВИТЬ CADDY (один раз)

     apt install -y caddy
     echo 'import /opt/lunka/Caddyfile' > /etc/caddy/Caddyfile

2. УКАЗАТЬ АДРЕС (IP сервера через ЧЁРТОЧКИ, не точки)

     echo 'DOMAIN=194-226-99-90.sslip.io' >> /opt/lunka/.env

   Для другого сервера — его IP: 1.2.3.4 → 1-2-3-4.sslip.io

3. ЗАПУСТИТЬ как обычно

     cd /opt/lunka && .venv/bin/python manager.py

   В начале появятся строки «Кабинет zarina: https://zarina.…sslip.io».
   Если Caddy не перезагрузился сам:  systemctl reload caddy
   Первое открытие кабинета может занять 10–20 секунд — Caddy получает
   сертификат. Дальше — мгновенно.

   Новые салоны получают адрес автоматически: <папка>.<DOMAIN>.


ЕСЛИ НЕ ОТКРЫВАЕТСЯ
     systemctl status caddy
     journalctl -u caddy -n 40
   • Порты 80 и 443 должны быть открыты (в панели хостинга — «Firewall»,
     если он там включён).


СВОЙ ДОМЕН (для солидности, ~200 ₽/год за .ru)
   1. Купите домен, например lunka-zapis.ru.
   2. В настройках DNS домена добавьте запись:  *  A  IP_СЕРВЕРА
      (звёздочка — чтобы работали zarina.lunka-zapis.ru, masha.lunka-zapis.ru…)
   3. В /opt/lunka/.env замените строку DOMAIN на:  DOMAIN=lunka-zapis.ru
   4. Перезапустите сервис. Кабинеты: https://zarina.lunka-zapis.ru


ПРИ ПЕРЕЕЗДЕ НА ДРУГОЙ СЕРВЕР
   Повторите шаг 1, а в .env поменяйте DOMAIN на IP нового сервера
   (или, со своим доменом, — поменяйте IP в DNS-записи).
