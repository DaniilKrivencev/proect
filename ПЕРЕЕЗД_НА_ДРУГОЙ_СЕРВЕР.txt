=====================================================================
  ПЕРЕЕЗД НА ДРУГОЙ СЕРВЕР (или с компьютера на сервер)
=====================================================================

ГЛАВНОЕ
  • Весь сервис — это ОДИН файл копии: код + базы ВСЕХ салонов + их настройки
    и токены ботов. Переезд = сделать копию → перенести файл → восстановить.
  • НИКОГДА не запускайте сервис на двух серверах одновременно: боты начнут
    «драться» за сообщения, а клиентки получат напоминания дважды.
    Сначала остановить старый — потом запустить новый.
  • Простой при переезде — 5–10 минут. Сообщения клиенток за это время
    не теряются: Telegram хранит их до суток и отдаст боту после запуска.
  • Копия содержит токены и телефоны клиенток — храните её как пароль.


ПЕРВАЯ ВЫКЛАДКА С КОМПЬЮТЕРА: СНАЧАЛА УБРАТЬ ТЕСТОВЫЕ ДАННЫЕ
  1. Закройте run.bat.
  2. Дважды щёлкните  очистить_сервис.bat :
       1 — стереть клиентов, записи, мастеров, чаты и владельца, но ОСТАВИТЬ ботов
           (их токены уже вписаны — на сервере боты сразу заработают);
       2 — удалить салоны целиком (пустой сервис, салоны добавите заново).
     Напишите слово ОЧИСТИТЬ. Копия всего, что было, сохранится РЯДОМ с папкой
     проекта (lunka_копия_до_очистки_….zip) — на сервер она не попадёт.
  3. Дважды щёлкните  сделать_копию.bat  — это и есть чистый сервис для сервера.
  4. Дальше — шаги 1, 3, 4, 5 ниже (шаг 2 не нужен — копия уже сделана).
  После запуска на сервере владелец салона заново нажимает «Подключить салон».


1. ПОДГОТОВИТЬ НОВЫЙ СЕРВЕР (сервис пока не запускаем)
   Сервер: Ubuntu 24.04. Подключитесь к нему (в панели хостинга есть
   «Консоль», или с компьютера командой  ssh root@IP_СЕРВЕРА) и выполните:

     apt update && apt install -y python3 python3-venv unzip curl
     mkdir -p /opt/lunka
     curl -L -o /usr/local/bin/cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64
     chmod +x /usr/local/bin/cloudflared       ← нужен для адреса кабинета

2. ОСТАНОВИТЬ СТАРЫЙ И СДЕЛАТЬ ФИНАЛЬНУЮ КОПИЮ
   • Старое место — компьютер с Windows:
       закройте окно run.bat → дважды щёлкните  сделать_копию.bat
       Файл появится в папке  backups  (например backup_2026-10-20_14-05.zip).
   • Старое место — сервер Linux:
       systemctl stop lunka          (если настроен автозапуск)
       cd /opt/lunka && .venv/bin/python manager.py backup

3. ПЕРЕНЕСТИ ФАЙЛ КОПИИ НА НОВЫЙ СЕРВЕР
   С вашего компьютера (Windows: «Командная строка», в папке с копией):
     scp backup_2026-10-20_14-05.zip root@IP_НОВОГО_СЕРВЕРА:/opt/lunka/
   С сервера на сервер — то же самое, выполнив команду на старом сервере.

4. ВОССТАНОВИТЬ НА НОВОМ СЕРВЕРЕ
     cd /opt/lunka
     unzip -o backup_2026-10-20_14-05.zip
     python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
     .venv/bin/python manager.py list        ← должны быть видны все салоны

5. ЗАПУСТИТЬ И ПРОВЕРИТЬ
     .venv/bin/python manager.py
   • В боте логов: /status — все салоны 🟢.
   • Сделайте тестовую запись с любого аккаунта, откройте кабинет.
   • Адрес кабинета меняется сам — кнопка «Кабинет» у всех обновится.

6. СТАРЫЙ СЕРВЕР
   Не удаляйте его 3–7 дней — просто держите выключенным. Если на новом что-то
   не так: остановить новый → запустить старый, и вы вернулись назад.


АВТОМАТИЧЕСКИЕ КОПИИ
  • Пока сервис работает, каждую ночь в 4:00 он сам делает копию в папку
    backups (хранятся последние 14). Вручную — сделать_копию.bat или
    python manager.py backup.
  • Хорошая привычка: раз в неделю скачивать свежую копию к себе на компьютер.

ВОССТАНОВЛЕНИЕ НА ЭТОМ ЖЕ МЕСТЕ (если что-то сломалось)
  • Windows: закройте run.bat, перетащите файл копии на  восстановить_из_копии.bat.
  • Linux:   python manager.py restore backups/backup_….zip
  Текущие данные не пропадут — они сохранятся в папку tenants_old_<дата>.

Автозапуск на сервере (чтобы сервис сам поднимался после перезагрузки) и
постоянный адрес кабинета на своём домене настроим, когда будет сервер, —
это отдельный небольшой шаг.
